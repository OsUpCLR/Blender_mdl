# Стекло в кораблях Star Conflict: как реализовано

Проверено по данным игры (распакованные модели + паки тестовой копии).

## Коротко

Стекло — **отдельный меш** (свой файл `.mdl-msh###`), материал `dyn_glass`,
у которого в `.mdf` **пустой блок**. Прозрачность и отражения даёт шейдер движка,
а не текстура.

## Доказательство: Raptor (`race3_l_t1`)

`.mdl-hdr`: 9 мешей, 3 материала.

| файл | материал | вершины | что это |
|---|---|---|---|
| `race3_l_t1.mdl-msh000` | 0 (`dyn_glass`) | 58 | стекло, тонкая оболочка |
| `race3_l_t1.mdl-msh001` | 1 (`ship_hull`) | 22 445 | корпус |
| `race3_l_t1.mdl-msh002` | 2 (`ship_decals`) | 116 | декали |

`.mdf`:

```
material dyn_glass
{
}
material ship_hull
{
	ColormapSampler      "models\ships\race_3\l\race3_l_t1_s1_d"
	Diffuse2Sampler      "models\ships\race_3\l\race3_l_t1_glow"
	DiffuseSampler       "models\ships\race_3\l\race3_l_t1_d"
	LightmapSampler      "models\ships\race_3\l\race3_l_t1_pdo"
	NormalSampler        "models\ships\race_3\l\race3_l_t1_nm"
	SpecularColorSampler "models\ships\race_3\l\race3_l_t1_msk_sc"
	UserParam2_Float4 ( 2 2 0 0 )
	pins
	{
		User1 1
	}
}
material ship_decals
{
	...
}
```

## Статистика по всем моделям игры

- `dyn_glass` встречается **393 раза**;
- у всех — блок **пустой**: ни сэмплеров, ни `pins`, ни `UserParam2`;
- других «стеклянных» материалов в моделях нет (`ship_glass`, `glass*` не встречаются);
- отдельных моделей вида `*_glass.mdl-hdr` для кораблей нет — стекло всегда меш внутри
  модели корабля (в паках нашлись только `mapskit`-стёкла уровня).

## Как делать правильно

1. В `.mdf` добавить блок (индекс материала — по порядку в файле):
   ```
   material dyn_glass
   {
   }
   ```
2. Стеклянную геометрию вынести в **отдельный объект** → отдельный `.mdl-msh###`;
   в заголовке меша `+0x00` = индекс `dyn_glass` в `.mdf`.
3. **Не добавлять** в `dyn_glass` сэмплеры, `pins`, `UserParam2` — это переключает
   вариант шейдера, и стекло перестаёт быть стеклом (становится непрозрачным или
   зеленеет).
4. Остальные меши — `ship_hull` / `ship_decals` с их полным набором сэмплеров.
5. Стекло можно делать двусторонним (движок рисует его без отсечения), но геометрия
   должна быть валидной: непустой меш, корректный `+0x18 = n_idx`, нулевые LOD.

## Грабли

| симптом | причина |
|---|---|
| стекло стало непрозрачным/зелёным | в `dyn_glass` добавили сэмплеры/`pins` или дали стеклу `ship_hull` |
| стекло не видно совсем | меш стекла не отдельный, материал не `dyn_glass`, или стекло отсекается (односторонние грани) |
| стекло «not bound» | блок `dyn_glass` заполнили текстурой, которой нет |
| стекло есть, но нет блика | это шейдер движка, текстом не лечится; влияют environment-текстуры уровня (`ship_specularity`, `ship_irradiance`) |

## Итог для новых моделей

В аддоне/пайплайне стекло надо собирать как **отдельный меш** с пустым материалом
`dyn_glass`; наш рабочий вариант Suigintou так и сделан: 2 материала —
`ship_hull` (полный набор) и `dyn_glass` (пустой), отдельные `.mdl-msh000/001`.

## Цвет стекла — в `.mdf` (уточнение)

Стекло — отдельные детали модели с материалом `dyn_glass`, а **цвет зашит в материал**,
игра его не вычисляет. Пример (`r1_h_t1`, стекло `msh001`/`msh005`, 80 вершин):

```
material dyn_glass
{
	UserParam0_Float4 ( 1 0.443 0.208 )              ; спектральный цвет (RGB)
	UserParam0_Float  ( 0.5 1 0 0 )                  ; x = прозрачность, y = глянец
	UserParam1_Float4 ( 0.000611 0.00228 0.00901 )   ; альбедо (почти чёрное)
}
```

У разных кораблей цвет свой:

| модель | spec (RGB) | opacity / gloss |
|---|---|---|
| r1_h_t1 | 1.0, 0.443, 0.208 (оранжевый) | 0.5 / 1.0 |
| r1_h_t3 | 0.037, 0.080, 0.067 | 0.5 / 0.7 |
| r1_h_t4 | 0.082, 0.043, 0.027 | 0.5 / 0.8 |
| r1_l_engineer | 0.040, 0.19, 0.19 | 0.5 / 1.0 |
| precursor `life_part4` | 0.258, 0.14, 0.080 | 0.8 / 1.0 |

Как рисуется: `materials/dyn_glass.mmp` — `DEFS UNFORM_SPECULAR_COLOR UNIFORM_ALBEDO
ALPHA_BLEND SPEC SHIP_CUBEMAP`; pins: `User3` — инвиз, `User5` — без DOF.
В `shaders/object.fx` (ветка `UNIFORM_ALBEDO`):

```
specColor   = UserParam0_Float4.rgb
glossFactor = UserParam0_Float.y
albedo      = UserParam1_Float4
```

Видимый цвет = спектральный цвет × отражения кубмапа + альбедо, с прозрачностью 0.5–0.8.

**Чего стекло не использует:** красители (ShipDyes) к нему не применяются (нет слоёв/pins);
инвиз и растворение (`User3`, `DISSOLVING`) меняют только прозрачность
(`CodeParam0_Float4`), цвет не трогают.

**Поменять цвет стекла** = одна строка `UserParam0_Float4 ( R G B )` в `.mdf` нужной модели.
